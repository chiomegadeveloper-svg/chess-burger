# Chess Burger v29

- Returning registered players land on a read-only Personal Profile after the splash screen.
- Profile details, avatar, country, and biography cannot be changed in view mode.
- The Personal Profile shows CBR, Gold points, win rate, match record, social counts, and biography.
- An Edit profile button opens the existing editable form.
- New users still receive the registration form automatically.

No database or Supabase SQL update is required.
