# Breathing idle characters

24 transparent WebP poses in `public/rpg/assets/idle/`, indexed by `rpg/src/character-idles.js`. Generated using the built-in image tool from the existing character attack artwork. Packed by `scripts/pack-rpg-idles.mjs` into 512px tiles with a maximum 200px silhouette and a shared 356px foot baseline.

The dedicated attack banner uses a 3.8 second CSS breathing loop, anchored at the feet. The opponent runs with an offset so both characters do not breathe in sync. Casting pauses and hides only the attacker until the existing ct.js attack finishes. Reduced-motion preferences disable breathing. Existing injury and death portraits remain in the main character panels; the banner uses the original death pose at zero HP.

Seven related tests passed, including padded silhouettes, attack substitution, hit timing, and all eight hero damage states. Browser fixture verification confirmed transparent backgrounds, no platforms in living idle poses, and return to idle after a real renderer attack.
