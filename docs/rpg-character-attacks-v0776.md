# RPG character attack sprites — v0.0776

All 24 existing characters have four attack poses: windup, attack, contact, recovery. Eight heroes face right by default; ten monsters and six bosses face left. Heroes mirror inward for either PvP side. Existing hero portraits and health-state art remain intact.

The ct.js/Pixi battle renderer draws both combatants inside the existing attack animation bar, with the attacker changing pose alongside the spell. Damage and health-state changes still occur once at the spell contact frame. Cancellation removes the animation without revealing queued damage. Assets preload when a battle opens.

Assets: `public/rpg/assets/attacks/<character-id>.webp`; mapping: `rpg/src/character-attacks.js`. Each atlas has four 512px square tiles, visible art at most 200px, at least 156px empty space on each side. Texture viewports exclude the excess padding when fitting the characters to the bar. Packing detects transparent row gaps and isolates connected artwork before placing it in padded tiles, preventing the uneven generated rows from including neighboring bosses.

Generated using the built-in image generation tool with contact sheets of the existing characters as identity references. Final prompt set:
