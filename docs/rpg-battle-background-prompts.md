# RPG battle backgrounds

Four separate panoramic 2172 × 724 WebP backgrounds for the RPG animation area. Created with the built-in image generation tool. Open foreground reserved for hero, monster and attack effects. Original PNG generation outputs are preserved separately; optimized WebPs are project assets under `public/rpg/assets/backgrounds/`.

Asset names: `mountain-sunset.webp`, `moonlit-kaiju-beach.webp`, `cloud-temple.webp`, `san-juanico-islands.webp`.

## Installation — v0.0784

The attack animation frame randomly selects one of the four scenes when a new battle ID first appears. It keeps that choice during turns, polling, harvesting, reopening and page reloads within the same browser tab. The last 24 battle choices are retained in session storage, with an in-memory fallback if browser storage is blocked. Successive battles may legitimately choose the same background.

The responsive frame uses an undistorted cover crop with a light dark overlay; foreground fighters and ct.js spell effects remain on top. No layout dimensions or combat rules changed. Six focused tests passed, including scene selection, persistence, storage failure, bounded history, existing sprite padding, contact timing and cancellation. Production build passed. Browser QA used the production scene selector, CSS and renderer in a temporary animation review harness; screenshot: `docs/images/rpg-battle-background-v0784.jpg`.
